What is MySQL?

  • An Open-Source Relational Database Management System (RDBMS).
  • Developed, distributed, and supported by Oracle Corporation.
  • Uses SQL (Structured Query Language) as its primary interface.
  • Stores data in highly organized tables, rows, and columns.
  • The backbone of many web applications (LAMP Stack: Linux, Apache, MySQL, PHP/Python/Perl).

Core Features

  • ACID Compliance: Ensures data Atomicity, Consistency, Isolation, and Durability (via InnoDB).
  • High Performance: Optimized query engine and fast memory caches.
  • Scalability: Handles massive databases with millions of records.
  • Security: Robust privilege and password system, with host-based verification.
  • Cross-Platform: Runs on Linux, Windows, macOS, and more.

System Architecture

  • Client-Server Model: Clients send SQL queries, the server executes them and returns results.
  • Connection Pool: Manages authentication, threads, and security.
  • SQL Interface: Parses, plans, and optimizes queries.
  • Pluggable Storage Engines:
         - InnoDB (Default, supports transactions)
         - MyISAM (Fast read-heavy ops, no transactions)

Essential Commands

  • DDL (Data Definition): CREATE DATABASE db_name; | CREATE TABLE tbl_name (...);
  • DML (Data Manipulation): INSERT INTO tbl_name VALUES (...); | UPDATE...
  • DQL (Data Query): SELECT * FROM users WHERE status = 'active';
  • DCL (Data Control): GRANT ALL PRIVILEGES ON db.* TO 'user'@'localhost';
